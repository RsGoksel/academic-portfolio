## How to cite

For the paper itself, cite the arXiv preprint directly.

folder at a specific commit:

> [Software]. GitHub.
> https://github.com/RsGoksel/academic-portfolio/tree/main/papers/darkweb-search-engine-audit

For the repository as a whole:
