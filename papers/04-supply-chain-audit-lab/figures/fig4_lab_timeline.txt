Auditing an unknown GitHub repository for supply-chain risk.

   minute     phase                  activity                                        artifact produced
   ------     -----                  --------                                        -----------------
   0          start                  introduction; instructor distributes URLs       (none)
   |
   +- 0-15    SETUP                  clone candidate + upstream into disposable VM   two cloned repos
   |          (15 min)               install lab tooling (file, unzip, sha256sum)    on student's VM
   |

   |
   +- 15-40   DISCOVERY              apply 10-point checklist to candidate           verdict sheet
   |          (25 min)               check 1-6, 8-10: pass superficially             with one FAIL

   |                                 unzip -l reveals .exe + .cmd + obfuscated .txt

   |

   |          (30 min)                                                                attack-defense

   END                               instructor collects deliverables                three artifacts/student:

                                                                                     2. mitigation paragraph
                                                                                     3. attendance

KEY MOMENTS (didactic):
   ~35 min:   student finds the ZIP. Reaction: "wait, what's a zip doing in .github?"
              This moment anchors the entire lab. Students who skipped check 7
              do NOT have this moment; instructor uses the discrepancy in §40-70.
   ~55 min:   discussion converges on "we need a tool that diffs against
              upstream and flags binaries." Instructor reveals forkdiff-audit.

SAFETY GATES (instructor enforces):
   throughout: no execution of any artifact in the candidate repo.
   throughout: all work in disposable VM or container.
   ~35 min:   unzip -l only, never unzip -x.
   end of lab: VM is destroyed; quarantined copy retained only by instructor.

PREREQUISITES:
   - git, pip, basic Linux CLI
   - one disposable VM per student (or shared container with student-scoped UID)
   - file, unzip, sha256sum on PATH
   - instructor has pre-vetted the two URLs and has the SHA-256 of the malicious
     artifact on a separate medium for post-lab verification
