# Paper 02 — Visual Classification of Tor Hidden Services with Frontier VLMs

> **ResearchGate publication:** _(link pending upload)_

A methodology proposal for classifying Tor hidden-service landing pages with
frontier vision-language models. The paper presents the pipeline design,
the ten-class label taxonomy, the evaluation protocol, and the proposed
ablations; it does not report executed measurements.
