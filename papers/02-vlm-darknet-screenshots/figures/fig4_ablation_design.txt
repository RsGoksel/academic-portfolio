Figure 4. Ablation design comparing visual and textual conditions
=================================================================

Condition matrix. The capture stage (Tor-aware Playwright fetch) is
identical across all rows; only the model input differs.

+----+----------------------------+----------------+-----------------+--------------------+
| #  | Condition                  | Model input    | Model           | Purpose            |
+====+============================+================+=================+====================+
| C0 | VLM on screenshot (primary)| screenshot     | Opus 4.7 / GPT-5| primary result     |
|    |                            |                | / UI2Code^N-9B  |                    |
+----+----------------------------+----------------+-----------------+--------------------+
| C1 | LLM on HTML (text-only)    | rendered HTML  | language part   | quantify visual    |
|    |                            |                | of same VLM     | signal contribution|
+----+----------------------------+----------------+-----------------+--------------------+
| C2 | VLM on screenshot,         | screenshot     | same VLM        | quantify JS-render |
|    | JS-on capture              | (JS rendered)  |                 | contribution       |
+----+----------------------------+----------------+-----------------+--------------------+
| C3 | VLM on screenshot,         | screenshot     | same VLM        | upper bound on     |
|    | extended capture delay     | (idle + 5s)    |                 | timing artefacts   |
+----+----------------------------+----------------+-----------------+--------------------+
| C4 | VLM on screenshot + HTML   | both modalities| same VLM        | upper-bound        |
|    | (fusion, reported only)    |                |                 | reference point    |
+----+----------------------------+----------------+-----------------+--------------------+

Reported per condition, per model:
    - per-class precision and recall over the 10-label taxonomy
    - weighted F1 across the 10 classes
    - full confusion matrix
    - cost per 1000 URLs (USD for APIs; GPU-hours for the open baseline)
    - self-consistency on the 10% repeated sub-sample (agreement rate, kappa)

Expected qualitative pattern (to be tested, not reported here):

    C0 > C1   on Marketplace, LeakSite, ImageboardOrChan, ServiceLanding
    C0 ~ C1   on Blog, Forum
    C2 > C0   on the ~10% JS-dependent sub-population only
    C4 >= C0  by a small margin; main effect from visual channel
