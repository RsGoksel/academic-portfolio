## Citation style

Numeric in-text citations `[N]`. Bibliography in plain author-year style at the end of
`PAPER.md`. No emoji. No URLs in citations unless the work is web-native and has no
print equivalent. arXiv IDs given for arXiv-hosted works.

## Hard rule on retrieval honesty

`PAPER.md` does not cite any work whose retrieval failed silently. Where a work is cited
without a local PDF, the citation appears only in a context where it supports a claim
made elsewhere by a confirmed PDF, and the bibliography flags non-retrieved works with a
footnote `(citation only; PDF not retrieved in this session)`.
